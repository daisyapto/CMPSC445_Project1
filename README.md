# CMPSC445_Project1
## Identifying Root Causes of Global Temperature Change Using Multi‑Source Data Integration and Regression Feature Ranking

Created data.csv with data obtained from the following links:
- https://gml.noaa.gov/ccgg/trends/
- https://data.giss.nasa.gov/gistemp/data_v4.html
- https://www.ncei.noaa.gov/data/total-solar-irradiance/access/yearly/
- https://ourworldindata.org/grapher/co2-long-term-concentration?overlay=download-data

*Note: The created data.csv includes the data collection of the csv files, merging them, and simple data preprocessing. The data.csv is unscaled data. Scaling occurs after the merged data is already saved into data.csv.
